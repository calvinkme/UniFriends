# UniFriends — Project Specification

## Overview
UniFriends is a mobile app for university students to connect and make friends. it sort of behaves like a dating app but our main goal is not for dating but for making friends. As we have realised that its hard to make friends in uni unless you join a ton of events, so hopefully this app will bridge that gap by introducing features that will make it easier to make friends.
